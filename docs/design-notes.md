# Оформление «Манускрипт» (дизайн тонкого клиента)

Источник: дизайн-прототип игрока (`docs/design/`). Ниже — выжимка системы,
внедрённой в `apps/web`. Прототип — референс внешнего вида, не код.

## Идея

Живая хроника на пергаменте. Проза — книжная антиква, механика проступает на
полях тёплой охрой. Раскол шрифтов зеркалит раскол нарратор/движок.

## Шрифты

- **Playfair Display** — заголовки, имена, заголовки полей гроссбуха, буквица.
- **Lora** — проза мастера и реплики игрока (реплики/ввод — курсив).
- **JetBrains Mono** — метки, числа, команды, чипы статуса.

Подключаются из Google Fonts в `app.html`; офлайн-фоллбэк — системная антиква/моно.

## Палитра (две темы)

Тема переключается `data-theme` (`light` = пергамент по умолчанию, `dark` = тушь),
тумблер ☾/☀ в топбаре + селектор в настройках. Токены — в `src/app.css`.

| Токен | Пергамент | Тушь |
|---|---|---|
| `--paper` (фон) | `#ECE6D6` | `#13171B` (радиальный градиент) |
| `--paper2` (приподнятая) | `#E5DDC9` | `#191E24` |
| `--panel` (гроссбух) | `#EFEADD` | `#1C222A` |
| `--field` (ввод/утоплено) | `#E0D7C2` | `#222932` |
| `--ink-color` (текст) | `#2C281F` | `#DDD7C9` |
| `--soft` (вторичный) | `#7C7565` | `#8C8F87` |
| `--accent` (бирюза) | `#2F7D72` | `#6FBFB2` |
| `--warm` (охра) | `#9C5B3B` | `#C98A5B` |
| `--danger` (сургуч) | `#A8503E` | `#CF6F57` |

Семантические (`--bg/--surface/--text/--border/...`) и легаси-имена
(`--vellum-100`, `--moon-300`, `--ink-900`, …) мапятся на палитру темы — компоненты
не привязаны к конкретным цветам.

## Ключевые элементы

- **Топбар** 54px: ☰ гроссбух · моно-чипы статуса по центру · 📚 кампании · 💳 справка · ☾/☀ тема · ⚙ настройки. ⊙ — индикатор связи.
- **Хроника** (колонка 660px): заголовок «Хроника»; проза мастера с **буквицей** (Playfair, охра) и аватаром ◈; реплика игрока — левая бирюзовая черта + метка «Ты» + курсив; системные строки — моно с ⟐; «Мастер пишет…» с анимированными точками.
- **Композер**: чипы команд (`/go /save /ask`) + выпадающее меню при вводе «/…» + поле с бирюзовой рамкой и квадратной кнопкой ➤.
- **Гроссбух**: заголовки полей — Playfair, охра, капитель, линия снизу; имя героя — Playfair.

## Не вошло (демо-флёр прототипа)

Прототип показывал также карту, лавку, диалоговые деревья, боевые стойки, «Книгу
мира», панель Режиссёра, модалки роста/предметов и быстрый старт по архетипам.
Это макетные сцены без серверной поддержки — в hosted-клиент не переносились
(механику ведёт детерминированный сервер, а не клиент). Внедрена **дизайн-система
и оформление существующих экранов**.
