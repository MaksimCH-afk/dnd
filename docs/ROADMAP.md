# Роадмап разработки

Привязка фаз ТЗ (раздел 20) к конкретным поставляемым артефактам. Статусы:
⬜ не начато · 🟡 в работе · ✅ готово.

---

## Фаза 0 — каркас 🟡

**Цель:** PWA + backend-прокси + конфиг ролей + первый запуск; базовый UI (хроника,
композер, стрим). Ход «ввод → Ведущий → проза» без состояния.

- ✅ Монорепо (pnpm workspaces), tooling, .gitignore, docs
- 🟡 `apps/proxy`: stateless-прокси к OpenRouter, `POST /llm/{role}` (SSE-стрим),
  `GET /health`, ретраи/бэкофф/фоллбэк, CORS, ключ из env
- 🟡 `apps/web`: SvelteKit PWA (manifest + service worker), хроника, композер, стрим прозы
- 🟡 `packages/engine`: конфиг ролей моделей, типы хода (turn), tool-схема (минимум)
- ⬜ Первый запуск (онбординг): ключ → синк → выбор моделей → Новая игра/Загрузить
- ⬜ Дизайн-токены (dark-first), типографика, «нить состояния» (визуальный каркас)

## Фаза 1 — общий слой + дельты (чинит №5) ⬜

core-персонаж, инвентарь/капитал, операции `Op[]`, транзакции, валидатор инвентаря,
`/save`+`/go` (git-синк), адаптивный блок статуса + гроссбух + нить состояния.

## Фаза 2 — создание персонажа + модули (R1) ⬜

Флоу раздела 5, проверка таланта к магии, маппинг направление→модули,
модуль-зависимые операции/UI; тест «воин/шпион без магии».

## Фаза 3 — карточки + scope + RAG (чинит №2, №3, №4) ⬜

Запертые карточки NPC, модель знания (scope/known_by), эмбеддинги (transformers.js),
scoped-контекст, guardrails валидатора, процедурная генерация NPC.

## Фаза 4 — подсистемы ⬜

Бой-резолвер, репутация/узнавание, экономика, время/путешествия, контракты,
локации, прогрессия (3 слоя), `/ask`. Подключение файлов правил.

## Фаза 5 — Режиссёр + мир-симуляция + seeds (чинит №1) ⬜

Теги арок, планировщик арок, офлайн-тики мира, отложенные последствия (seeds).

## Фаза 6 — полировка ⬜

Фоллбэк-профили, ретраи, кросс-девайс, UI (анимации/темы/доступность/экраны
сейвов/кампании), миграции схемы, прогон критериев приёмки (раздел 16).
