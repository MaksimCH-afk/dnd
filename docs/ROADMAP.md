## Фаза 0 — каркас ✅

**Цель:** PWA + backend-прокси + конфиг ролей + первый запуск; базовый UI (хроника,
композер, стрим). Ход «ввод → Ведущий → проза» без состояния.

- ✅ Монорепо (pnpm workspaces), tooling, .gitignore, docs
- ✅ `apps/proxy`: stateless-прокси к OpenRouter, `POST /llm/{role}` (SSE-стрим),
  `GET /health`, `/embed` (501-стаб), ретраи/бэкофф/фоллбэк по кандидатам, CORS, ключ из env
- ✅ `apps/web`: SvelteKit PWA (manifest + service worker, офлайн-оболочка), поток хроники,
  композер (Enter/Shift+Enter, чипы /go /save /ask), SSE-стрим прозы, панель настроек
- ✅ `packages/engine`: конфиг ролей моделей (дефолты ТЗ §6), схема `Op[]` (§8.1),
  контракт с бэкендом (§18.6)
- ✅ Дизайн-токены (dark-first, §18.2), типографика (антиква/моно), «нить состояния»
  (визуальный каркас, idle-режим), «оседание чернил» (курсор стрима), reduced-motion
- 🟡 Первый запуск (онбординг) — частично: настройки прокси + проверка `/health` +
  выбор темы/размера. Полный мастер (ключ для прямого режима → git-репо → выбор моделей →
  Новая игра/Загрузить) **отложен в Фазу 1–2**: до появления состояния и save/load
  загружать/создавать пока нечего; ключ в Фазе 0 живёт в `apps/proxy/.env`.

- **Управление ключами из фронтенда** 🟡 — добавить/изменить/сохранить/удалить/проверить;

`docs/rules-notes.md`.
