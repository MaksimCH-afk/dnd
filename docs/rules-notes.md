# Что правила задают движку (партия 1)

Извлечённые из файлов правил факты, влияющие на модель данных, enum'ы и маппинги
движка. Источник истины — сами файлы в `rules/`; здесь — инженерная выжимка.

Контент правил версии **3.0**. Партия 1: `commands.md`, `creation.md`, `magic.md`,
`master.md`, `progression.md`. Ожидается партия 2: `world.md`, `religions.md`,
`systems.md` (числовые таблицы боя/времени/экономики — детерминированное ядро).

> **Маппинг окружения.** Файлы написаны под старую среду (проект в Клоде:
> `/mnt/user-data/uploads` для чтения, `/mnt/user-data/outputs` для записи).
> В нашей архитектуре: правила → `rules/` (read-only), состояние → отдельный
> git-репо канона (JSON + md-экспорт). Поведение `/go /save /ask` переносится,
> пути — нет.

---

## 1. Файлы состояния → сущности движка

`commands.md`/`master.md` определяют динамические файлы. Маппинг на сущности
(ТЗ §4) и md-экспорт:

| Файл правил (md) | Сущности канона (JSON) | md-экспорт |
|------------------|------------------------|------------|
| `char_sheet.md` | `character.core` + активные `character.modules` | да |
| `char_inventory.md` | `inventory` + `capital` | да |
| `current_session.md` | `session` (+ скрытые `seeds`, заметки мастера) | да |
| `npc.md` | `npc[]` | да |
| `locations.md` | `locations[]` | да |
| `contracts.md` | `contracts[]` | да |

**Критичные для `/go`** (без них игра невозможна): `char_sheet`,
`char_inventory`, `current_session`. Нет критичного → `/go` СТОП и просит загрузить.

## 2. Общий слой персонажа (`character.core`) — поля из `master.md` §1

- идентичность: имя, раса, возраст, направление(я);
- **HP** (тек/макс) — открыто игроку;
- **выносливость** (тек/макс);
- **состояние Силы** (если маг) — состоянием, не числом;
- **тип мага** (черпающий/своесильный) — если маг;
- статусы/эффекты/ранения (с примерным сроком заживления);
- **особенности словами** (`features[]`): «Опытный переговорщик», «Привычен к холоду»;
- **специализации** (поворотные);
- **владение школами** + уровень мастерства словом (если маг);
- **тёмные дуги** — описанием, не цифрой;
- **репутация** — уровнями/словами по фракциям;
- строка «обновлено: День X, время».

> **Скрытые числа** (STR/DEX/CON/… и точные модификаторы, мастерство числом,
> прогресс тёмных дуг) движок ведёт у себя, в лист игрока НЕ выносит (ТЗ §4.1).

## 3. Инвентарь и капитал (`char_inventory.md`)

- **капитал**: текущая сумма + 2–3 последние операции с причиной (журнал);
- **экипировка** (надето), **инвентарь** (предмет, кол-во, заряды артефактов),
  **схроны/хранилища**, состояние снаряжения;
- обновлять при КАЖДОЙ трате/доходе/находке; находки логичны (валидатор §7.3).

**Валюта (`master.md`):** `1 GP = 10 SP = 100 MP`; **серебро (SP) — основная монета**.
Капитал храним в MP (медь) как наименьшую целочисленную единицу → без дробей;
отображаем по контексту (преим. SP). Цены/диапазоны — из `systems.md` (партия 2).

## 4. Магия (модуль `magic`) — `magic.md`

Enum'ы для движка:

- **Состояние Силы** (`PowerState`, скрыто/грубо): `Полон` · `Расходует` ·
  `На исходе` · `Истощён`. (Уже в `packages/engine/src/ops.ts`.)
- **Тип мага** (`MageType`): `черпающий` (внешник; зависит от Мест Силы, каст
  можно сорвать; быстрое восстановление у источника) · `своесильный` (внутренник;
  независим от места, резерв конечен, восстановление только отдыхом).
- **Уровень мастерства школы** (`MasteryLevel`): `Новичок` → `Ученик` → `Умелый`
  → `Мастер` → `Архимаг` (скрытый, грубый).
- **Масштаб эффекта** (для оценки затрат Силы): `Бытовой` · `Малый` · `Серьёзный`
  · `Великий` · `Легендарный`.

**Школы** (`MagicSchool`) и принадлежность к тёмной цене:

| Школа | Тёмная цена | Тип мага (типично) | Легальность |
|-------|-------------|--------------------|-------------|
| Стихийная (академическая) | — | черпающий | легальна |
| Природная | — | черпающий | терпима |
| Божественная | — (цена: вера/служение) | черпающий | легальна по культу |
| Аура | — (лёгкая самопотеря, опц.) | черпающий | редкая |
| Иллюзии | — (мягкий флавор-риск) | любой | запретна |
| Кровавая (некромантия) | **Коррупция** | своесильный | запретна, инквизиция |
| Тёмная | **Деградация** | своесильный | запретна |
| Разума/памяти | **Распад памяти** | своесильный | запретна, инквизиция |
| Светлая | **Годы жизни** | своесильный (своя жизнь) | почитаема, редка |

**Тёмные дуги** (`DarkArc`, для `darkcost.advance`): `Коррупция` · `Деградация` ·
`Распад памяти` · `Годы жизни`. Двигаются ТОЛЬКО за переступающие акты, редко и
веско; показываются нарративом, не числом. Рутина не трогает их никогда.

**Каст (резолвер, гибрид движок/нарратор):** намерение → 3 оси (Сила хватит? в
рамках школы/воображения? удастся — скрытый `d20 + мастерство + моды` vs сложность)
→ исход: успех / «да, но…» / провал-искажение (частичный / обратный удар / вспышка
внимания / дикое искажение). Каст тратит **и Силу, и выносливость**. Срыв каста —
урон → проверка концентрации (детали боя — `systems.md`, партия 2).

**Комбинации:** Светлая↔Тёмная — критический конфликт; тёмные цены складываются;
тип мага важнее школы для восстановления.

## 5. Создание персонажа (`creation.md`) — флоу Фазы 2

Шаги: 1) основы (раса/возраст/направление; скрытые атрибуты+HP); 2) проверка
таланта к магии (скрытая) → тип мага + одна открытая школа уровня «Новичок» по
направлению (академик→стихийная, жрец→божественная домена, друид→природная) или
начальная форма тёмной дорожки; редкие школы (аура/иллюзии/разум) на старте
недоступны; 3) **потолок старта** (способный, не прокачанный — жёсткое правило);
4) стартовая репутация; 5) капитал+экипировка (+скрытый бросок удачи); 6) стартовая
локация по направлению; 7) хук; затем `current_session` + первая сцена.

**Шкала репутации** (`ReputationTier`, ориентир из `creation.md`):
`Почитаемый/Легендарный` · `Уважаемый/Ценимый` · `Известен/Нейтрален` ·
`Подозрительный/Нелюбимый` · `Презираемый/Ненавидимый` · `Враг/Заклятый враг`.
Старт: светлый → `Нейтрален` (с перекосами раса/направление); тёмный →
`Подозрительный`.

**Стартовая локация по направлению** (`creation.md` §3) — таблица для дефолтов.
**Старт по умолчанию:** День 1, утро, весна.

## 6. `current_session` (точка возврата) — шаблон из `creation.md` §6

Поля сущности `session`: дата (день/время/сезон), локация (место+регион), погода;
**ТЕКУЩИЙ МОМЕНТ** (2–4 предложения); «знает / не знает»; доступные действия;
активные NPC; известная информация и слухи; таймеры; **возможные хуки (скрыто)** →
`seeds`; **заметки мастера (скрыто)**. Скрытые блоки в лист игрока не выводятся.

## 7. Прогрессия (`progression.md`) — три слоя

- **Слой 1 — скрытый уровень:** числа/мастерство растут тихо от практики (движок
  ведёт счётчики боёв/кастов/применений).
- **Слой 2 — особенности словами:** редко (≈раз в несколько дней, после значимого)
  → `feature.grant`.
- **Слой 3 — специализации:** очень редко, после критического события →
  `specialization.offer` (выбор 2–3).
- Бытовые навыки — строкой по логике, без «курсов с таймерами». Значимый рост
  (бой/ремесло/магия) требует учителя/времени/практики; учитель может отказать.
- **Что мир запоминает** (чек-лист, 10 направлений): репутация, отношения, финансы,
  время, сюжет, мораль/психика, магия, религия, тело, статус. → ориентир для `seeds`.

## 8. Команды (`commands.md`)

- **`/go`**: классифицировать файлы (критичные/правила/опц.) → читать (не по
  памяти) → синтез точки возврата → краткий отчёт (формат ниже) → ждать
  подтверждения → возобновить БЕЗ автопрогрессии времени. В нашем движке «читать
  файлы» = загрузить канон из git + собрать `session`.
- **`/save`**: обновить динамические сущности (всегда core+inventory+session;
  остальное при изменениях) → экспорт md + git commit. Правила не трогать.
- **`/ask`**: мета-режим, выводит мастера из роли; раскрывает скрытую кухню
  (броски, состояние Силы числом, причины реакций NPC, тёмные дуги, репутацию).
  Типы: А механика · Б логика мира · В броски · Г ошибка мастера. Читает внутренний
  лог хода (ТЗ §11). Источник для движка — `/ask`-лог: броски, дельты, scope, модули.

**Формат отчёта `/go`** (≤30 строк) и **блок статуса** (`master.md` §ФОРМАТ ОТВЕТА):

```
⏰ [время] (День X)   📍 [локация]
💰 [капитал] SP   💚 HP [X/Y]   ✦ Сила: [состояние]
```

Сила — состоянием, не числом. Строку не раздувать. Блок адаптивен под модули
(ТЗ §18.5): Сила — только если активен `magic`.

## 10. Детерминированное ядро (`systems.md`) — для Фаз 1/4

**Атрибуты** (`Attr`, скрытые, модификаторы в бросках): `STR` (урон ближний/переноска),
`DEX` (точность/уклонение/скорость/AC/скрытность/стрельба), `CON` (HP/выносливость/
стойкость), `INT` (знания/магия акад./иллюз./мент./концентрация), `PER` (внимательность/
ложь/засады), `CHA` (убеждение/торг/лидерство).

**Производные (создание персонажа, Фаза 2):**
- **HP** ≈ `CON × (5..7)` + поправка направления/закалки. 0 HP = смерть.
- **Выносливость** ≈ `CON × 10`.
- Точные значения — скрытый бросок движка на создании; хранятся в core.

**Бой (резолвер, Фаза 4):** непрерывное время, без раундов.
- Атака: `1d20 + STR|DEX + качество оружия + стиль + ситуация`.
- AC: `10 + DEX + броня + щит + стиль + ситуация`. Попадание: атака ≥ AC.
- **Стили** (`CombatStyle`): агрессивный (AC−2,атк+2) · обычный (0,0) · оборонительный
  (+2,−2) · только защита (+5,−5) · безрассудный (−5,+5).
- Крит (нат.20): ×2 урон + эффект. Провал (нат.1): автопромах + осложнение.
- **Урон оружия** (кости): кинжал 1d4, кор.меч 1d6, дл.меч 1d8, двуручный 2d6,
  топор 1d8/1d12, копьё 1d6–1d8, лук 1d6–1d8, арбалет 1d10.
- **Скорость действий** (скрыто, «кто раньше»): кинжал 1–2с, меч 2–3с, двуручный
  4–5с, лук 3–4с, арбалет(перезар.) 6–8с, парир/уклон 1–2с, смена оружия 3–5с,
  сближение 5м 2–3с. Моды: DEX↑; ср.броня −10%, тяж. −20%; усталость −30%; рана −20/−50%.
- **Раны по % потерянных HP** (`WoundStage`): лёгкая 0–25% (нет штрафов) · средняя
  26–50% (−2, −20% скор., кровь −2HP/10с) · тяжёлая 51–75% (−5, −50%, кровь −5/10с,
  шок) · критическая 76–99% (только защита, кровь −10/10с, отключка 30–60с) · смерть 0HP.
- **Выносливость** (`StaminaState`): 60–100% бодр · 40–59 устал (−2,−10%) · 20–39
  сильно устал (−5,−30%) · 1–19 изнеможение (−10,−50%) · 0 упал. Каст тратит Силу+вынос.
- **Концентрация каста под уроном:** `DC = max(10, урон/2)`; черпающим легче сорвать.
- **Враги (HP-тиры):** слабые 5–15 · обычные 30–50 · опытные 60–80 · монстры 50–200.
  Проверяют **мораль** (раненые/брошенные бегут/сдаются).

**Время (`systems.md` ч.II):** год 360 дней = 12 мес × 30; сезоны зима(1–3)/весна(4–6)/
лето(7–9)/осень(10–12); неделя 7 дней. Время суток влияет на лавки/опасность/видимость.
- **Путешествия (км/день):** пешком 30–40 (форсир. 60–70), верхом 80–100 (форсир.
  150–200), повозка 30–50, корабль 200–400. Моды: груз −30%, тяж.броня −20%, дорога
  +20%, бездорожье −40%, дождь −20%, снег −40%, ночь без света −50%.
- **Заживление (HP/сутки):** кор.отдых +5 разово · сон +10 · постельный +20 · лекарь +30.
  Сроки ран: лёгкая 2–3 дня, средняя ~неделя, тяжёлая 2–3 нед, критич. 1–2 мес.
- **Восстановление Силы:** сон — полностью; черпающим — приток у Мест Силы; своесильным
  только время/покой.
- **Время каста:** боевой 1–5с, простой ритуал 5–15мин, сложный 30–60мин, мощный 2–6ч,
  эпический 1–3 дня.

**Экономика (резолвер цен, Фаза 4):** `1 GP = 10 SP = 100 MP`, серебро основное.
Вес: ~50 монет = 1 кг. **Цена = базовый диапазон категории × множитель региона ×
сезон × торг(CHA −10..−20%)**. Диапазоны (в SP, если не указано): хлеб 2–5 MP; ночлег
койка 5 / комната 10–20 / люкс 50–100; кинжал 10–200, дл.меч 150–5000, латы 3000–10000;
лекарь 10–300, жрец-исцеление 50–2000; наёмник-воин ~300/мес, боевой маг 3000–15000;
лошадь 500–1000; зелье исцеления 50–10000; магпредметы: расходники 30–200, малые
1000–2500, средние 5000–15000, мощные 30000–100000+, легендарные — бесценны.
- **Множители региона** (`RegionMultiplier`): столица еда×1.5/товары×1.3/услуги×2.0/
  недвиж×3.0; кр.город 1.2/1.1/1.5/2.0; ср.город ×1.0; деревня 0.7/1.3/0.6/0.5;
  глушь 0.5/2.0/0.3/0.3. Наценка: базовое 20–40%, редкое 50–100%, магия 200–500%.
- Крупные суммы → банки (~1%/мес хранение), расписки, драгоценности (сюжетный фактор).

## 11. Мир (`world.md`)

**Расы** (`Race`, срок жизни + восприятие, для создания и реакций NPC):

| Раса | Жизнь, лет | Черты / восприятие в обществе |
|------|-----------|-------------------------------|
| Люди | 60–90 | адаптивны, «норма», у власти |
| Светлые эльфы | 300–500 | хрупки, магически одарены, высокомерны, редки в городах |
| Тёмные эльфы (дроу) | 200–400 | ночное зрение/скрытность/яды; **повсеместное недоверие** |
| Гномы | 150–250 | выносливы, **устойчивы к магии**, мастера камня/металла, клановы |
| Полурослики | 80–120 | ловки, удачливы, незаметны, устойчивы к страху |
| Орки | 40–60 | сильны, быстро восстанавливаются; **презираемы/пугают** |
| Полуэльфы | 120–180 | универсальны, посредники, часто одиноки |

Возраст: молодость (сила, мало опыта) / зрелость (баланс) / старость (мудрость, слабее
телом) — по меркам расы. **Регионы:** Центральные земли, Северные королевства (недоверие
к магии), Южные города-государства (рабство, торговля), Западное побережье (республики/
пиратство), Восточные джунгли. Особые: царства гномов, эльфийские анклавы, орочьи степи.
**Космология:** Материальный мир / Источник (План Силы) / Сумрак / Чертоги Усопших;
**Места Силы** (магия щедрее) и **Искажённые Земли** (дикая магия). Сословия: знать,
духовенство, купцы/ремесленники, крестьяне, крепостные, рабы (юг), преступный мир.

## 12. Религии и культы (`religions.md`) — модули `faith` / `intrigue`, узнавание

**Три круга легальности** (`Legality`): легальные · полулегальные · запретные.

| Культ | Домен | Круг | Заметки для движка |
|-------|-------|------|--------------------|
| Церковь Солнца | свет/жизнь/исцеление/порядок | легальн. | госрелигия; **Инквизиция** |
| Орден Серебряной Луны | мудрость/магия/алхимия | легальн. | академии, гибок, кроет «науку» |
| Храм Порядка | закон/справедливость | легальн. | судьи-жрецы, с Инквизицией |
| Круг Природы | природа/звери | легальн.(глушь) | друиды/шаманы |
| Культ Войны | сила/честь | полулег. | боевые благословения |
| Культ Смерти | смерть/покой | полулег. | **НЕ некроманты**, против нежити |
| Культ Знания | знание/память | полулег. | хранят запретное знание |
| Культ Алой Луны | кровь/жизн.сила | полулег.(тень) | кровавая магия; **сдерживает Коррупцию** (сюжет) |
| Культ Теней | тьма/воля/душа | запретн. | тёмная магия; сеть одиночек |
| Культ Проклятых | нежить/некромантия | запретн. | изгои-монстры, путь к личеству |
| Культ Обмана | хитрость/тени/обман | полу/запр. | гильдия воров/убийц → `intrigue` |

**Инквизиция** — крыло Церкви Солнца + Храм Порядка; охотится на запретные школы
(кровавая, тёмная, разума, иллюзии, некромантия); артефакты-детекторы; арест/пытки/казнь.
→ **Связь с багом №3 и seeds:** применение запретной магии при достаточной известности/
репутации порождает `seeds` (инквизиция задаёт вопросы). Домены ↔ божественная магия
(`magic.md`). Союзы/вражда культов — источник арок (Режиссёр, Фаза 5).

## 13. Новые требования (после получения всех файлов)

- **Горячая загрузка версий правил.** Все 9 файлов — основа механики и должны
  обновляться без пересборки: фронт хранит правила в `RulesStore` (IndexedDB),
  засеянном из bundled `rules/`; пользователь может загрузить новую версию любого
  файла (с версией/датой); движок и сборка промптов читают правила из стора.
  В каноне (git-репо) правила — защищённая директория (ТЗ §15), `/save` их не трогает.
- **Управление ключами из фронтенда.** Ключ(и) не в скрытом `.env`, а под управлением
  UI: добавить / изменить / сохранить / удалить / проверить. Прокси остаётся stateless
  и получает ключ из запроса; `.env` — только опциональный сид для локального запуска.
