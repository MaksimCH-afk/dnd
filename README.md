# Текстовое НРИ (соло) — local-first PWA

Самостоятельное приложение для одиночной текстовой ролевой игры в эпическом фэнтези-мире.
Заменяет связку «проект в Клоде + .md-файлы» на приложение с **детерминированным движком
состояния** (источник истины) и **LLM-рассказчиком** через OpenRouter.

Полная спецификация: см. `docs/TZ.md` (ТЗ v1.1).

## Принципы

1. **Разделение ролей.** Движок хранит состояние структурно, применяет изменения
   транзакционно, бросает кости, считает цены/время/бой. LLM генерирует прозу и
   *предлагает* изменения операциями (tool-calls), но не хранит правду и не бросает кости.
2. **Сборко-агностичность.** Персонаж — любое направление (воин, наёмник, шпион, маг,
   жрец, ремесленник, торговец…). Общий слой + подключаемые модули способностей.
   Магия — один из модулей, а не основа системы.
3. **Local-first.** Канон состояния — структурный JSON в git-репозитории. Синхронизация
   между устройствами через git. Backend — тонкий stateless-прокси только к LLM.

## Структура репозитория

```
.
├── docs/                  # ТЗ и документ-роадмап
├── rules/                 # файлы правил мира (world.md, magic.md, …) — read-only контент
├── packages/
│   └── engine/            # детерминированный движок состояния (TS, фреймворк-агностичный)
└── apps/
    ├── web/               # SvelteKit PWA (UI + движок в браузере + RAG + git-клиент)
    └── proxy/             # Node/TS бэкенд-прокси к OpenRouter (stateless)
```

## Стек

- **Фронтенд:** TypeScript + SvelteKit, PWA (manifest + service worker, офлайн-оболочка).
- **Движок:** TypeScript, исполняется в браузере; фреймворк-агностичный пакет.
- **Бэкенд:** Node + TypeScript, один прокси-эндпоинт к OpenRouter (хранит API-ключ).
- **RAG:** `transformers.js` (`bge-m3` / `multilingual-e5`) локально — фаза 3.
- **Синхронизация:** `isomorphic-git` + git-репозиторий с каноном состояния.

## Ключевые свойства

- **Ключи API — под управлением UI:** добавить / изменить / сохранить / удалить /
  проверить из фронтенда. Прокси stateless, получает ключ из запроса (без скрытого `.env`).
- **Файлы правил — горячо заменяемы:** 9 md-файлов в `rules/` — основа механики;
  новые версии грузятся из UI без пересборки (`RulesStore` в IndexedDB). См. `rules/README.md`.

## Разработка

```bash
pnpm install
pnpm dev          # запустить web + proxy параллельно
pnpm dev:web      # только фронтенд
pnpm dev:proxy    # только прокси
```

Бэкенду нужен ключ OpenRouter — скопируйте `apps/proxy/.env.example` в `apps/proxy/.env`.
