# Текстовое НРИ (соло) — ваша личная ролевая игра

Это приложение водит для вас текстовую ролевую игру в тёмном фэнтези-мире: вы пишете,
что делает ваш герой, а «мастер» (ИИ) описывает мир, события и реакции. Все цифры,
кости, инвентарь и сюжет надёжно считает само приложение — ИИ только рассказывает.

Играть можно **с компьютера и с планшета**, продолжая с того же места.

> Эта инструкция рассчитана на обычного пользователя. Делайте по шагам — ничего
> программировать не нужно, только установить две вещи и копировать команды.

---

## Что понадобится

1. **Компьютер** (Windows, macOS или Linux) — на нём работает «движок» игры.
2. **Ключ OpenRouter** — это доступ к ИИ-моделям. Есть бесплатные модели.
   Получить: [openrouter.ai](https://openrouter.ai) → войти → раздел **Keys** → создать ключ
   (строка вида `sk-or-v1-…`). Скопируйте её — понадобится один раз.
3. *(по желанию)* **Аккаунт GitHub** — если хотите, чтобы сохранения сами
   синхронизировались между компьютером и планшетом.

## Часть 1. Установка на компьютер (один раз)

### Шаг 1. Установите Node.js

Скачайте и установите **LTS-версию** с [nodejs.org](https://nodejs.org). Установка
обычная, «Далее → Далее → Готово».

Проверка: откройте терминал (Windows — «PowerShell»; macOS — «Терминал») и введите:

```bash
node -v
```

Если показалась версия (например `v22.x.x`) — всё хорошо.

### Шаг 2. Установите pnpm

В том же терминале:

```bash
corepack enable
```

**На macOS** эта команда часто выдаёт ошибку прав (`EACCES … permission denied … /usr/local/bin`).
Это нормально — поставьте pnpm официальным скриптом (без прав администратора):

```bash
curl -fsSL https://get.pnpm.io/install.sh | sh -
```

Затем **закройте Терминал и откройте заново**. Проверьте: `pnpm -v` — должна показаться версия.
(Альтернатива с паролем Mac: `sudo corepack enable`.)

> Подсказка: чтобы перейти в папку проекта, наберите `cd ` (с пробелом) и
> перетащите папку в окно Терминала — путь подставится сам.

### Шаг 3. Скачайте приложение

Самый простой способ — кнопкой: на странице проекта на GitHub нажмите зелёную
кнопку **Code → Download ZIP**, распакуйте архив в удобную папку.

Или, если знакомы с git:

```bash
git clone https://github.com/MaksimCH-afk/dnd.git
```

### Шаг 4. Установите зависимости

Откройте терминал **в папке проекта** и введите один раз:

```bash
pnpm install
```

(Пойдёт загрузка — это нормально, нужно подождать минуту-другую.)

### Шаг 5. Запустите приложение

```bash
pnpm dev
```

В терминале появится строчка вида `Local: http://localhost:5173`. Откройте этот
адрес в браузере (Chrome или Edge). **Терминал не закрывайте** — пока он открыт,
игра работает.

### Шаг 6. Первый запуск в браузере

Откроется мастер настройки. По шагам:

1. **Ключ** — вставьте ключ OpenRouter из «Что понадобится» и нажмите «Проверить».
2. **Синхронизация** — можно пропустить (см. Часть 3, если хотите играть и на планшете).
3. **Модели** — оставьте по умолчанию.
4. **Старт** — нажмите **«Новая игра»**, выберите расу и направление героя — и играйте.

Готово 🎉

## Часть 2. Играть с планшета (Android)

Планшет открывает ту же игру в браузере, а считает всё по-прежнему компьютер.
Поэтому **компьютер должен быть включён, с запущенным приложением, и в той же
Wi-Fi-сети**, что и планшет.

### Шаг 1. Разрешите доступ из сети

В папке `apps/proxy` создайте файл `.env` (скопируйте из `.env.example`) и впишите
строку:

```
CORS_ORIGINS=*
```

Это разрешает планшету обращаться к компьютеру в вашей домашней сети.
Перезапустите приложение (`Ctrl+C` в терминале, затем снова `pnpm dev`).

### Шаг 2. Узнайте адрес компьютера в сети

- **Windows:** в PowerShell введите `ipconfig`, найдите строку «IPv4-адрес»
  (например `192.168.1.50`).
- **macOS/Linux:** введите `ipconfig getifaddr en0` или `hostname -I`.

Это и есть адрес компьютера, например `192.168.1.50`.

### Шаг 3. Откройте игру на планшете

В браузере планшета (Chrome) откройте:

```
http://192.168.1.50:5173
```

(подставьте адрес вашего компьютера из шага 2).

### Шаг 4. Укажите адрес «мотора» игры

На планшете откройте **⚙ Настройки** в приложении и в поле **«Адрес прокси»**
впишите:

```
http://192.168.1.50:8787
```

Вставьте ключ OpenRouter (как на компьютере). Готово — можно играть.

### Шаг 5. (по желанию) Установить как приложение

В меню браузера на планшете выберите **«Добавить на главный экран»** —
появится иконка, и игра будет открываться как обычное приложение.

## Часть 3. Синхронизация ПК ↔ планшет (по желанию)

Чтобы сохранения сами переезжали между устройствами, приложение умеет хранить их
в вашем личном репозитории на GitHub.

1. Создайте на GitHub **новый пустой репозиторий** (можно приватный).
2. Создайте **токен доступа**: GitHub → Settings → Developer settings →
   Personal access tokens → дайте права на запись в репозиторий. Скопируйте токен.
3. В приложении (⚙ Настройки или мастер первого запуска) включите
   **«Синхронизация канона через git»**, впишите адрес репозитория и токен,
   нажмите «Проверить».

Дальше: **`/save`** отправляет сохранение, **`/go`** на другом устройстве —
подтягивает его. Так можно начать на ПК и продолжить на планшете.

## Как играть: команды

В поле ввода можно писать обычными словами, что делает герой. Есть три команды
(кнопки над полем ввода):

- **`/go`** — продолжить / загрузить (с синхронизацией — подтянуть с другого устройства).
- **`/save`** — сохранить игру.
- **`/ask`** — «спросить мастера» вне игры: покажет скрытую кухню (что выпало на
  костях, почему NPC так отреагировал) — то, что в самой игре остаётся за кадром.

Сверху справа: **📚** кампании (несколько героев/прохождений), **📖** файлы правил,
**🎬** Режиссёр (подкинуть новый сюжетный поворот), **⚙** настройки.

## Каждый следующий запуск (коротко)

1. Открыть терминал в папке проекта.
2. Ввести `pnpm dev`.
3. Открыть `http://localhost:5173` (или адрес ПК — с планшета).

## Если что-то не работает

- **«Нет ключа OpenRouter»** — добавьте ключ в ⚙ Настройки → «Ключ OpenRouter» → «Проверить».
- **«Мир замер: нет связи с моделью»** — проверьте интернет; на бесплатных моделях
  бывают очереди — попробуйте ещё раз, приложение само пробует запасную модель.
- **Планшет не открывает игру** — компьютер и планшет должны быть в одной Wi-Fi-сети;
  проверьте адрес из Части 2; убедитесь, что в `apps/proxy/.env` стоит `CORS_ORIGINS=*`
  и приложение перезапущено; брандмауэр компьютера может спрашивать разрешение — разрешите.
- **`pnpm: команда не найдена`** — вернитесь к Части 1, шаг 2 (установка pnpm).
- **macOS: `corepack enable` → `EACCES permission denied`** — поставьте pnpm скриптом
  `curl -fsSL https://get.pnpm.io/install.sh | sh -`, перезапустите Терминал
  (или `sudo corepack enable` с паролем).
- **Порт занят** — закройте старый запущенный терминал с игрой и запустите заново.

## Для технических пользователей

Монорепо (pnpm workspaces): `apps/web` (SvelteKit PWA + движок состояния в браузере),
`apps/proxy` (тонкий stateless-прокси к OpenRouter, Node/TS), `packages/engine`
(детерминированный движок — источник истины). Спецификация — `docs/TZ.md`,
дорожная карта и статус — `docs/ROADMAP.md`, список моделей — `docs/models.md`.

```bash
pnpm install      # установка
pnpm dev          # web (:5173) + proxy (:8787)
pnpm -r check     # типы
pnpm --filter @rpg/engine test    # тесты движка
pnpm --filter @rpg/web smoke      # сквозной прогон связок
pnpm build        # прод-сборка
```

Ключ OpenRouter управляется из UI (не из файлов). Файлы правил (`rules/*.md`) —
основа механики, заменяются прямо в приложении (📖). Канон игры — в git-репозитории,
файлы правил при сохранении не трогаются.
