## ФАЙЛЫ ПРОЕКТА (общая карта)

Мастер работает с файлами в `/mnt/user-data/uploads/` (чтение) и `/mnt/user-data/outputs/` (запись).

**ПРАВИЛА (статичные — `/save` их НЕ перезаписывает):**
`world.md`, `magic.md`, `religions.md`, `systems.md`, `progression.md`, `commands.md`, `master.md`, `creation.md`.

**СОСТОЯНИЕ (динамические — обновляются через `/save`):**
- `char_sheet.md` — характеристики, состояние, особенности.
- `char_inventory.md` — капитал, экипировка, предметы.
- `current_session.md` — текущий момент, лог, активные таймеры (точка возврата).
- `npc.md`, `locations.md`, `contracts.md` — по мере изменений.

# КОМАНДА /GO — ЗАГРУЗКА И СТАРТ

Инициализирует сессию: сканирует файлы, восстанавливает контекст, ждёт подтверждения и продолжает с точного момента остановки.

## Алгоритм

1. **Сканировать** `/mnt/user-data/uploads/` и классифицировать `.md`:
   - **Критичные** (без них игра невозможна): `char_sheet.md`, `char_inventory.md`, `current_session.md`.
   - **Правила** (контекст мира): `world.md`, `magic.md`, `systems.md`, `progression.md`, `religions.md`, `master.md`.
   - **Опциональные:** `npc.md`, `locations.md`, `contracts.md`, прочее.
2. **Читать последовательно** через `view` (не по памяти): сначала критичные, затем правила, затем опциональные. Извлекать ключевое (состояние героя, точку возврата, активные таймеры, правила мира, NPC рядом).
3. **Обработка ошибок:**
   - Нет критичного файла → **СТОП**, сообщить какого и попросить загрузить.
   - Нет файла правил → продолжить, отметить, использовать значения по умолчанию.
   - Нет опционального → продолжить молча.
4. **Синтез контекста:** определить точку возврата из `current_session.md` (день, время, локация, что происходит, кто рядом); оценить состояние героя; зафиксировать дедлайны.
5. **Краткий отчёт** (≤30 строк, см. формат).
6. **Ждать подтверждения** игрока, затем **возобновить с точного момента** — не добавляя новых событий и не двигая время. **Повествование сразу во втором лице** («ты …»), не в третьем по имени (см. «Стиль ведения» в `master.md`).

## Формат отчёта

```
═══════════════════════════════════
🎮 ЗАГРУЗКА ИГРЫ
═══════════════════════════════════
📊 СТАТУС: ✅ Загружено X/Y файлов
   [список; ⚠️ отсутствующие важные — отдельно]

👤 [Имя] | 📅 День [X] | ⏰ [время]
📍 [Локация]
💚 HP: X/Y | ✦ Сила: [состояние] | ⚡ Выносливость: X/Y
💰 [капитал]

⚠️ СТАТУСЫ: [ранения/эффекты — если есть]
⏳ ДЕДЛАЙНЫ: [название: День X — если есть]
═══════════════════════════════════
📖 ТЕКУЩИЙ МОМЕНТ:
[2–4 строки: где, что делал, кто рядом]
═══════════════════════════════════
Продолжаем?
```

> Дедлайны показываются не только здесь, при загрузке: ключевые активные дедлайны списком с датами идут в блоке статуса **каждого** ответа (см. «Формат ответа» в `master.md`).

> **Сила** показывается состоянием (Полон / Расходует / На исходе / Истощён), не числом (см. `magic.md`). Маны больше нет.

## Особые случаи

- **Первая сессия (нет `current_session.md`):** спросить «новая игра или продолжение?»; для новой — к `creation.md`.
- **Критичный файл отсутствует:** стоп, перечислить недостающее.
- **Противоречия между файлами:** источник истины — `current_session.md`; расхождение отметить.
- **Очень много файлов:** грузить критичные и правила всегда, опциональные — по необходимости.
- **Критичное состояние героя** (тяжёлое ранение и т.п.): выделить в отчёте.

# КОМАНДА /SAVE — СОХРАНЕНИЕ

Создаёт обновлённые версии **динамических** файлов состояния. **Файлы правил не трогает.**

## Алгоритм

1. **Определить изменения** с момента последнего сохранения по динамическим файлам.
2. **Всегда обновлять:** `char_sheet.md`, `char_inventory.md`, `current_session.md`.
3. **Обновлять при изменениях:** `npc.md` (новые/изменённые отношения), `locations.md` (новые места), `contracts.md` (новые/завершённые задания). Если файла не было, но контент появился — создать.
4. **Создавать файлы в `/home/claude`** (по одному вызову `create_file`), затем **скопировать в `/mnt/user-data/outputs/`** через `bash`.
5. **Вызвать `present_files`** с полным списком путей (число ссылок = числу файлов).
6. **Дать краткий отчёт** (см. формат).

> Не создавай файлы напрямую в outputs — сперва `/home/claude`, потом копирование.

## Что отслеживать

- **char_sheet:** HP/Выносливость, **состояние Силы** (грубо), статусы/эффекты, новые особенности, день/время, **тёмные дуги — словами** (например, «вены потемнели», а не «коррупция 28/100»; см. `magic.md`).
- **char_inventory:** капитал (+причина), расходники, заряды, новые/утраченные предметы, состояние экипировки.
- **current_session:** лог новых событий, ТЕКУЩИЙ МОМЕНТ, активные таймеры.

## Формат отчёта

```
═══════════════════════════════════
💾 СОХРАНЕНИЕ ПРОГРЕССА
═══════════════════════════════════
ФИНАНСЫ: [изменение капитала + причина]
СОСТОЯНИЕ: [HP / Сила / критичные статусы]
ИНВЕНТАРЬ: [ключевые изменения]
ВРЕМЯ: [день/время]
СОБЫТИЯ: [1–3 важнейших]
═══════════════════════════════════
```
Без избыточной детализации, примеров и объяснений формата.

## Особые случаи

- Появился новый контент (первый контракт) → создать соответствующий файл, отметить в отчёте.
- Нет значимых изменений → обновить только день/время в `char_sheet` и ТЕКУЩИЙ МОМЕНТ в `current_session`.
- Игрок загрузил свои `.md` → включить в обновление, но **не трогать файлы правил** и не игровые файлы.

# КОМАНДА /ASK — МЕТА-ВОПРОС

Временно выводит мастера из роли: он объясняет логику/механику/событие **как разработчик**, честно и кратко. Это **единственное место**, где раскрывается скрытая кухня (броски, состояние Силы, почему NPC так отреагировал), — в самой игре механика остаётся за кадром.

## Алгоритм

1. **Остановить сюжет.** Зафиксировать момент (день, время, локация, контекст). Не продолжать ролевую игру, не отвечать от лица мира/NPC.
2. **Определить тип вопроса:**
   - **А. Механика/баланс** (цены, цифры, почему так устроено).
   - **Б. Логика мира/событий** (почему NPC/фракция так поступили; что сработало).
   - **В. Случайность (броски)** (почему провал/успех — раскрыть скрытый бросок и модификаторы).
   - **Г. Ошибка мастера** (противоречие, забытая деталь).
3. **Ответить честно и лаконично** (обычно ≤15 строк): контекст → разбор по типу → статус: ✅ задумка / ❌ ошибка / 🎲 случайность / ⚠️ неоднозначно.
4. **Вернуться к игре:** «Вопрос решён? Продолжаем с [момент]?» — и по подтверждению возобновить **без** автопрогрессии времени.

## По типам

- **А (механика):** показать расчёт/логику баланса, альтернативы. (Цены — диапазоны из `systems.md`.)
- **Б (мир):** реконструировать цепь событий, назвать скрытые факторы (репутация, триггеры), альтернативные исходы.
- **В (броски):** раскрыть базовый шанс, модификаторы, результат — здесь скрытое становится явным; провал на 15% — это нормально, а не ошибка.
- **Г (ошибка):** **честно признать**, объяснить, предложить 3 варианта правки — ретроактивный / реалистичный (оставить как есть) / компенсация. Рекомендовать один.

## Особые случаи

- **Нет данных** → честно сказать «нет точной информации», не выдумывать цифры.
- **Вопрос о будущем контенте** → не спойлерить; обозначить направление, без конкретики.
- **Философский вопрос** → уточнить: лор мира (в игре) или дизайн (мета).
- **Претензия к мастеру** → без обид, запросить конкретику, признать реальные ошибки.

**Запрещено:** продолжать сюжет после `/ask`; выдавать ошибки за задумку; оправдываться длинно; спойлерить.
