# Файлы правил мира

Эта директория содержит **read-only** контент правил, на который опирается движок и
из которого собираются выдержки для промптов (см. ТЗ раздел 7 «распределение правил»).

Файлы правил (версия контента — 3.0):

| Файл | Содержимое | Статус |
|------|-----------|--------|
| `commands.md` | поведение команд `/go /save /ask`, форматы отчётов | ✅ есть |
| `creation.md` | флоу создания персонажа, направления, потолок старта, шаблон `current_session` | ✅ есть |
| `magic.md` | магия: Сила, два типа магов, школы, тёмные дуги | ✅ есть |
| `master.md` | философия ведения, спеки листов, формат статуса, чек-листы | ✅ есть |
| `progression.md` | прогрессия (3 слоя), особенности, специализации, «что мир запоминает» | ✅ есть |
| `world.md` | мир, расы, регионы, деньги, экономические множители | ⏳ ожидается |
| `religions.md` | боги, домены, культы, легальность, инквизиция | ⏳ ожидается |
| `systems.md` | бой, время, экономика: таблицы, кости, цены, скорости, раны | ⏳ ожидается |

Что эти файлы значат для движка (модель данных, enum'ы, маппинги) — см.
`docs/rules-notes.md`.

**Важно (ТЗ раздел 15):** файлы правил — защищённая директория, приложение их
не перезаписывает. Канон игрового состояния живёт в ОТДЕЛЬНОМ git-репозитории,
не здесь.

> Пока реальные файлы не предоставлены, движок работает с этим контентом как с
> опциональным: подсистемы, зависящие от конкретных таблиц (бой, экономика —
> Фаза 4), подключают правила через слой `packages/engine/src/rules`, который
> деградирует gracefully при отсутствии файла.
