# Файлы правил мира

Эта директория содержит **read-only** контент правил, на который опирается движок и
из которого собираются выдержки для промптов (см. ТЗ раздел 7 «распределение правил»).

Ожидаемые файлы (будут добавлены владельцем проекта):

| Файл | Содержимое |
|------|-----------|
| `world.md` | мир, расы, регионы, деньги, экономические множители |
| `magic.md` | магия: школы, состояние Силы, тёмные дуги |
| `religions.md` | боги, домены, культы, легальность, инквизиция |
| `systems.md` | бой, время, экономика: таблицы, кости, цены, скорости, раны |
| `progression.md` | прогрессия, особенности, специализации, «что мир запоминает» |
| `master.md` | философия ведения, формат сцены, чек-листы guardrails |
| `creation.md` | флоу создания персонажа, направления, потолок старта |
| `commands.md` | поведение команд `/go /save /ask` |

**Важно (ТЗ раздел 15):** файлы правил — защищённая директория, приложение их
не перезаписывает. Канон игрового состояния живёт в ОТДЕЛЬНОМ git-репозитории,
не здесь.

> Пока реальные файлы не предоставлены, движок работает с этим контентом как с
> опциональным: подсистемы, зависящие от конкретных таблиц (бой, экономика —
> Фаза 4), подключают правила через слой `packages/engine/src/rules`, который
> деградирует gracefully при отсутствии файла.
